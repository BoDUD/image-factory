# V2 实现追踪

v0.4.0 不是 V2 全量交付。功能按设计书 A–E 分阶段推进。

## 已实现并自动化测试

- 中文桌面，模板和名单拖入，字段匹配、记忆、试出与批量导出。
- 多模板统一队列与名单快照、命名占位符、客户或模板分类目录、保留目录的 ZIP。
- Excel/CSV/TXT，编码、多工作表选择，输入异常处理。
- JSON 图片模板：文字、槽位、背景及框图。
- SQLite、暂停、取消、恢复、哈希校验和不覆盖提交。
- 静态水印、平铺、混合、预设；镜像、裁切、缩放、模糊、宫格、二维码。
- 本地目录图库搜索、送往工具箱、ZIP 与校验清单。
- GIF 逐帧贴膜、循环、时长、卡帧、资源限制及取消。
- v0.3.0：水印自由拖动和等比缩放、比例坐标预设、现有 JSON 文字和图片框布局编辑及另存。鼠标坐标、实际队列输出与预览一致性、新旧预设均有测试。

- v0.4.0：JSON 模板可视化新建、文字/头像/编号区域增删、属性编辑、画布与背景设置。编号规则随模板保存，按名单顺序生成，支持单模板、多模板与恢复。

## 已编写但缺少真实 Photoshop 验证

- 独立 COM 子进程、固定 JSX；点文字层扫描和替换。
- 文档副本处理、当前文档快照、PNG/JPG 保存。
- 字体缺失和混合样式检测；需检查各 PS 版本接口差异。

## 仍待实现

- PSD 效果组选择及更多高级命名选项。
- 透明孔洞识别和手绘标。
- 图库相册数据库、标注记忆、目标体积压缩、横竖拼接。
- 二维码回读、缺字完整检测、字体安装、ICC 色彩管理。
- FFmpeg 视频、音轨同步、人脸检测与人工蒙版、视频跟踪。
- 深层智能对象、GIF 转可播放 PSD、隐形水印实验。
- 邮件及网盘的账号授权、回执、超时核对与幂等发送。
- QQ 指令、闪传、文件和群管理：先逐项验证公开接口。

未实现功能不以假按钮或伪成功记录代替；UI 明确显示当前边界。
