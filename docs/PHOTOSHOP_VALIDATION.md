## 有 Photoshop 后的实机验收

使用已安装并可正常启动的 Windows 桌面 Photoshop 和有权使用的测试模板，在单独测试目录进行：

1. 记录 PS 版本，连接并扫描包含中文点文字、嵌套组和多字段的 PSD。
2. 以姓名、编号测试名单替换，检查中文、前导零、长文字及标点；与手工成品对照。
3. 对 PNG/JPG 检查尺寸、透明度、字体、图层样式和颜色。缺失字体及混合样式应报明确信息。
4. 记录原 PSD 哈希；打开一份有未保存改动的用户文档，再测试“当前文档”和批量出图。检查文件哈希、未保存改动和活动文档是否受到影响。
5. 测试取消、桥接超时及恢复；确认不终止用户 Photoshop，不覆盖已有成品。
6. 记录每项通过/失败、样例文件与输出截图。只有完成这些项目后才更新兼容状态。

复杂智能对象、动态 PSD 和特殊图层效果不属于本次已验收能力。
