# Image Factory · 本地出图工坊

根据《PSD 批量出图助手设计书 V2》实现的 Windows 桌面程序。
**当前 v0.4.0，尚未覆盖设计书 V2 全部阶段。**

## v0.4.0 新建模板、区域和自动编号

1. 一键改图页点击“新建模板”。在设计器中设置画布尺寸、背景颜色或背景图片。
2. 点击“添加文字”“添加头像”或“添加自动编号”，选择区域后拖动位置和右下角调整大小。点击“区域属性”修改字段名、字号、文字颜色、预览文字或编号规则；可删除多余区域。
3. 自动编号支持起始值、正整数步长、最少位数和前缀。例如起始 98、步长 2、位数 4、前缀 VIP-，生成 VIP-0098、VIP-0100。超过位数时不会截断。
4. 刷新成品预览，另存 JSON 模板。示例头像和预览文字不会成为客户数据；导入名单后绑定文字列和头像文件路径列。头像按区域等比填满并居中裁切。
5. 点击试出或一键改图。编号按有效名单顺序生成，第一条使用起始值，每个模板独立编号；暂停或恢复同一批次不重新编号。重新排序名单会改变新批次的编号。

编辑已有 JSON 模板不再要求先导入名单。编号不需要绑定名单列，纯编号模板仍需导入名单以确定出图数量。背景和字体引用本机路径，迁移电脑时需迁移素材。PSD 图层编辑、透明孔洞识别仍未实现。

## v0.3.0 可视化拖动编辑

- 贴膜页选择底图和水印，点击“打开可视化编辑”，拖动水印位置、拖右下角等比缩放，调整透明度后应用到整批图片。
- 自由位置按画布比例保存，支持不同尺寸图片；水印预设保存自由坐标，同时兼容 v1 预设。自由编辑应用后关闭平铺，取消不改变原设置。
- 一键改图页载入 JSON 模板和客户名单，点击“拖动编辑模板布局”，选择文字或图片区域，拖动位置和大小，刷新成品预览后另存。
- v0.3.0 仅能编辑现有 JSON 区域，v0.4.0 增加新建字段。另存保留原模板；引用素材使用本机绝对路径，不是可跨电脑搬运的素材包。多模板篮子中的旧模板需移除后重新加入。
- Photoshop 环境检查会明确提示未安装，不会把环境检查当作 PSD 实机验证。验证准备说明见 `docs/PHOTOSHOP_VALIDATION.md`。

## v0.2.0 多模板与分类出图

- 先导入一份客户名单，再同时拖入多个 PSD/JSON 模板。字段能自动匹配或已有有效配置时，直接加入多模板批次；未匹配时明确提示单独绑定。
- 也可以逐个载入模板、设置字段后点击“加入多模板批次”。每个模板记住加入时的名单快照，支持查看和移除。
- 点击“运行多模板批次”统一出图，界面显示模板数与总张数。
- 命名支持 `{customer}`、`{template}`、`{row_id}`、`{date}`、`{index}`；日期在批次创建时固定。可按客户或模板分类。
- 恢复保持原命名与目录结构；ZIP 保留子目录，避免不同客户文件混在一起。
- 原 v0.1.0 批次数据库无需迁移，可继续恢复。

## 快速体验

Windows 便携包解压后运行 `ImageFactory.exe`，请保留同目录 `_internal` 文件夹。GitHub Actions 构建通过后可以下载 `ImageFactory-Windows` 构建产物。

1. 点击“生成并载入示例”，无需 Photoshop 即可测试。
2. 3 条中文姓名与编号自动匹配到字段。
3. 选择成品目录，点击“一键改图”，查看 PNG 成品。
4. “任务与交付”可刷新批次、恢复任务和导出 ZIP。

使用自己的 PSD：启动 Windows Photoshop → 在“连接与范围”检测连接 → 拖入 PSD 与 Excel/CSV/TXT → 绑定字段 → 试出 → 批量生成。
**Photoshop 桥接已编写，但本次开发环境没有 Photoshop，尚未进行真实 PSD 兼容验收。** 先用副本和少量记录测试。

## 源码运行

安装 Python 3.11 或更新版本，双击 `setup.bat`，然后用 `start.bat` 启动。或运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python.exe -m image_factory
```

依赖在 Python 3.14 / Windows 验证；CI 使用 Python 3.12。

## 模板与客户表

PSD 统一样式的点文字层推荐命名 `TEXT__customer`、`TEXT__order_id`。扫描嵌套组但不进入智能对象；段落和混合样式文字报错。调整最大文字宽度，超过时缩小到 12pt，仍超出则失败。复杂字体、文字路径、特效和 PS 版本不作通用兼容承诺。

无需 Photoshop 的 JSON 模板：

```json
{
  "version": 1,
  "size": [900, 900],
  "background": "#e7f5f1",
  "text": [{"field": "customer", "box": [80, 300, 740, 150], "size": 88, "min_size": 24, "color": "#17564b", "align": "center"}]
}
```

可选 `background_image`、`frame` 相对于模板定位；`text[].font` 指定字体文件，默认优先 Windows 微软雅黑。
图片槽位：`"slots": [{"field":"avatar","box":[20,20,300,300]}]`。名单单元格填图片路径，相对路径以名单目录为基准。槽位等比填满并居中裁切。首版尚未自动检测全部缺字。

客户 CSV：

```csv
姓名,编号
今今,A001
小星星,A002
```

TXT 每行一位客户。XLSX 前导零编号须设为文本；数字单元格的显示格式不会恢复为字符串。重复姓名保留独立序号。

## 数据与恢复

- 成品目录 `.factory/jobs.sqlite3` 保存输入快照和哈希；不要删除，否则不能恢复原批次。
- 同一输出目录进程互斥，哈希相符成品跳过，冲突不覆盖；输入改变后建立新批次。
- 通过同文件系统硬链接原子提交，推荐本地 NTFS；FAT/exFAT 或部分网盘目录可能不支持，会明确报错。
- Photoshop 在副本中修改，超时不杀死用户的 Photoshop。检查处理状态后再恢复；原稿保护待实机验证。
- PSD 转 sRGB；Pillow 路线暂不做完整 ICC 转换，精确色彩素材请先转 sRGB。
- 素材名单默认不上传，运行无需服务器。
